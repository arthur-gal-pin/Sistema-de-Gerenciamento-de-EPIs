# 📚 Projeto Sistema de Gerenciamento de Ensaios de EPI's

Seja Bem-vindo ao **Sitema de Gerenciamento de Ensaios de EPI's**.
Este repositório contém a documentação e implementação de um sistema de um sistema de gerenciamento de ensaios virtuais.

## 🎯 Objetivo

Projeto acadêmico em parceria com a Fundacentro que tem o objetivo de desenvolver um projeto que auxilie o gerenciamento de Ensaios de EPI's da Instituição. Este projeto será desenvolvido através de conceitos de programação ensinados em aulas, o sistema visará  permitir o agendamento de EPI's, registrar e acompanhar os testes realizados. O sistema aborda conceitos como:

* Desenvolvimento de APIs para gerenciamento de dados
* Modelagem de banco de dados para registro de ensaios
* Organização de código no back-end
* Integração entre front-end e back-end
* Registro e consulta de informações padronizadas

## 🛠️ Tecnologias Utilizadas

### 🌐 Front-end

* HTML5
* CSS3
* JavaScript
* React

### ⚙️ Back-end

* Node.js
* Express

### 🗄️ Banco de Dados

* SQLServer

## 📌 Observações

Diferentemente de um sistema comum de gerenciamento de tarefas, esta nova aplicação tem como objetivo desenvolver e organizar os ensaios e verificações dos EPI's (Equipamentos de Proteção Individual). Será possível registrar os resultados de cada teste em um sistema padronizado, permitindo o acesso a todos os funcionários. a solicitação veio diretamente da Fundação “Jorge Duprat Figueiredo”, de Segurança e Medicina do Trabalho (Fundacentro) , uma Fundação Pública do Governo do Brasil vinculada ao Ministério do Trabalho e Emprego.
